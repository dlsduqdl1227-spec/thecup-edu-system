# 교육자료 한국어 / English

18개 과정·레벨의 기존 슬라이드를 같은 순서로 영문 제공한다. 한국어 원본 JSON은 변경하지 않는다.

## 사용 및 권한

- 교육자료 화면의 한국어 / English 버튼으로 전환한다. 현재 페이지와 선택 언어를 유지한다.
- 관리자만 발표자 노트와 PPTX 다운로드를 사용할 수 있다. 영문 PPTX에는 `_EN`을 붙인다.
- `GET /api/edu/decks/{course}/{level}?lang=ko|en`은 기존 로그인·개별 레벨 권한을 먼저 확인한다. 기본 언어는 한국어다.
- 번역 사전은 서버에서만 읽는다. 공개 정적 파일이나 클라이언트 번들에 교육 본문 전체를 넣지 않는다.
- 번역 누락은 503으로 안내하며, 언어 전환 실패 시 기존 화면은 유지한다. 신규 한국어 문장을 추가하면 영문 사전도 갱신해야 한다.

## 번역 유지보수

`en.json`은 자동번역 후 용어·일부 문장·수치 표현을 보완한 자료다. 공식 SCA 영문 교재가 아니며, 강사의 영문 전문 검수는 별도로 권장한다. 전체 문장에 대한 전문가 검수 완료를 의미하지 않는다.

1. `scripts/translate-edu-local.mjs`는 Chrome의 기기 내 번역 모델로 교육 본문만 처리한다. 모델 다운로드 후 오프라인에서 번역한다. 회원·운영 데이터를 읽지 않는다.
2. 번역 초안은 Git에서 제외된 `outputs/i18n-tools/en-draft.json`에 저장한다. 사용법·실행 인자는 해당 스크립트를 참고한다.
3. 수동 교정은 `en-overrides.json`에 한국어 원문을 정확한 키로 넣는다.
4. `node scripts/review-edu-english.mjs`로 최종 사전을 생성한다. 이후 타입 검사·lint·테스트·브라우저 검수를 반복한다.

## 영문 플레이버 휠

사용자가 보유한 SCA 자료의 원본 영문 이미지를 사용한다. 저작권 표시를 유지하며, 이미지와 PDF를 공개 저장소나 `public/`에 넣지 않는다.

로컬 검수 이미지는 `outputs/sca-assets/flavor-wheel-en.png`이다. 운영에서는 기존 보호 자산 테이블의 별도 `flavor-wheel-en` 항목으로 제공하며, 기존 이미지 권한 검사를 그대로 적용한다. `node scripts/prepare-edu-assets.mjs outputs/sca-assets flavor-wheel-en`으로 해당 자산만 준비할 수 있다. 운영 자산 등록은 코드 호환성 확인 후 별도로 수행한다.

## 검수

- `tests/sca-english.test.mjs`: 18개 레벨의 번역 완전성, 원본 보존, 숫자형 차트 데이터 일치, 권한·노트 차단, PPTX 파일명.
- `qa/sca-english-check.mjs`: 격리 로컬 DB로 관리자/수강생 전환, 실패·재시도, 영문 이미지/PPTX, 360·768·1440px, 권한 회수 확인.
- `QA_PLAYWRIGHT`는 Playwright 모듈 경로, `QA_BROWSER`는 Chrome 실행 파일 경로다. 먼저 `qa/vite.config.mjs`로 로컬 QA 서버를 실행한다. 운영 주소에 이 테스트를 실행하지 않는다.

## 2026-10-13 운영 편집 기능 보존

운영 Worker의 2026-09-30 버전에만 있던 페이지 편집·저장 기능과 최신 원문을 복원하여 통합했다. 18개 한국어 덱의 직렬화 결과, 페이지 ID, 운영 수정 기록의 source hash가 기존 운영본과 동일함을 대조했다. `edu_slide_edits`의 기존 행은 읽어서 표시하고, 관리자가 저장할 때만 수정한다. 수강생에게 편집 메타데이터는 제공하지 않는다. 운영 DB 마이그레이션은 필요하지 않으며 기존 테이블을 재생성하지 않는다.

관리자가 영문 화면에서 `Edit Korean original`을 누르면 같은 페이지의 한국어 원문으로 전환해 기존 편집창을 연다. 새로 입력한 한국어 문장이 사전에 없으면 영문 API는 503과 한국어 이용 안내를 반환하며, 이전 번역으로 수정 내용을 숨기지 않는다. 새 문장의 영문 번역을 추가한 뒤 다시 배포해야 한다. 현재 운영에 저장된 수정 본문은 이번 번역에 포함했다. 재고 수정은 별도 미배포 작업이다.
